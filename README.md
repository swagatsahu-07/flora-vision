# FloraVision — Modern Plant E-Commerce UI

A premium, visually rich plant e-commerce frontend built with **React + Vite**, featuring **glassmorphism**, **custom SVG UI**, and a clean, modern layout structure.

---

## Project Overview

FloraVision is a fully responsive UI designed to showcase plant collections with a minimalist and nature-centric visual approach.

Key highlights:
- Custom glass-effect plant cards  
- Perfectly curved SVG borders  
- Dynamic hero section  
- Customer review system  
- Section headings with decorative corners  
- Smooth, modern UI transitions  

---

## Tech Stack

- **React (Vite)**
- **TailwindCSS**
- **Custom SVG Masks**
- **PNG Assets**
- **Vercel Deployment**

# Installation & Setup

Follow the steps below to run this project locally:

### 1️. Clone the Repository
```bash
git clone https://github.com/swagatsahu-07/flora-vision.git
```

### 2. Move into the Project Folder
```bash
cd <your-repo>
```

### 3. Install Dependencies
```bash
npm install
```

### 4️. Start the Development Server
```bash
npm run dev
```

### 5️. Build for Production
```bash
npm run build
```

### 6️. Preview the Production Build (Optional)
```bash
npm run preview
```
